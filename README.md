# HL Panel

Mini panel de Telegram para controlar HL Casero desde el celular. Se abre con el botón **🎛 Panel** del bot.

- No guarda datos ni tiene claves: el bot le pasa el estado en la dirección (`#d=...`) y la página le devuelve
  lo que tocaste con `Telegram.WebApp.sendData`, que solo llega a tu chat con el bot.
- Publicado con GitHub Pages: https://gastonpalma96.github.io/hl-panel/
